# 常见问题

| 现象 | 检查和处理 |
|---|---|
| 双击窗口报找不到 Python | 安装 Python 3.11+，启用 launcher 或 PATH；重新打开终端验证版本 |
| 安装依赖失败 | 查看 pip 原始错误，检查网络与包索引；使用 `.venv\Scripts\python.exe -m pip install -e .` 重试 |
| 面板打不开 | 保持启动终端运行，检查输出端口；确认浏览器和服务在同一系统；检查端口冲突 |
| Windows 来源不可用 | 运行 `capture-doctor --open-interface`；确认 Npcap 回环接口及权限；仅能枚举接口不等于能捕获 |
| 面板在线但 0 条 | 确认 CC Switch 监听已发现；启动捕获后发新请求；查看来源错误；旁路不支持 TLS、HTTP/2 或 WebSocket |
| WSL 后端有记录但面板无记录 | 检查来源的快照发布错误、目录写权限和心跳；不要手动复制运行中的 WAL/SHM；停止本项目后保留数据再排查 |
| 显式代理连接失败 | 检查代理是否启动、供应商 base_url 是否正确、`--upstream` 是否重复 `/v1` 或指回 CC Switch |
| 网关拒绝响应 | 查看逐次尝试与最终回显；核对实际模型名、门槛和字段支持；缺失字段无法判定通过 |
| 停止后客户端不能请求 | 显式代理/网关需先恢复供应商原 base_url；旁路模式无需恢复路由 |
| Windows 与 WSL 的 localhost 不互通 | 使用原先可达的 CC Switch 入口，或在客户端所在系统运行代理；不要假设 NAT 与 mirrored 网络相同 |

反馈问题请提供版本、系统、启动命令（去掉密钥）、模式、错误摘要与可复现步骤。不要贴完整真实请求、认证头或私有会话路径。基础回归测试仅使用模拟流量，不代表当前机器的驱动或真实上游已验证。
